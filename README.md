## 🚀 Getting Started

### For Development
```bash
# Clone the repo
git clone https://github.com/felixdujadin222/ComplyNG.git
cd ComplyNG

# Open in browser
start index.html
```

### Enable GitHub Pages
1. Go to **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / Folder: `/ (root)`
4. Save

Site will be live at: `https://felixdujadin222.github.io/ComplyNG/`
